Kyron Runtime Detailed Design
#############################

The detailed design of Kyron Runtime lives in the source code, as rustdoc module documentation
(``//!``) and item documentation, next to the implementation of each unit. Design
rationale and ``SAFETY`` justifications for ``unsafe`` code are kept at the code they describe.
